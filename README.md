# AGI — кофейные демо

Полные исходники четырёх самостоятельных проектов. Каждый содержит готовый статический сайт в `dist/`, локальные ресурсы и собственную инструкцию.

## Запуск

Из корня репозитория: `python3 -m http.server 8000`. Откройте `http://localhost:8000/showcase/dist/` или соответствующую папку другого проекта. Сборка и установка зависимостей для запуска не требуются.

Для размещения на статическом хостинге используйте содержимое `dist/` выбранного проекта. Сохраняйте структуру ресурсов и import map для проектов с Three.js.

## Проверки

- Engrave: `cd engrave && npm test`.
- 3D-слайдер: `cd showcase && node --experimental-loader ./tests/vendor-loader.mjs --test tests/*.test.js`.

При переносе 12 октября 2026 прошли 15 тестов, проверка синтаксиса JavaScript и локальных ссылок на ресурсы. Браузерная проверка в этой среде недоступна.

Модели, изображения, шрифты, лицензии, генераторы и тесты сохранены вместе с проектами. Атрибуция и ограничения исходных материалов приведены в README и файлах лицензий каждого проекта.
